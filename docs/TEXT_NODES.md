# Eagle 文本节点结构

所有节点都位于 `🦅 Eagle Suite/文本`，不再增加第二层菜单；下表只说明职责，不代表菜单层级。

| 职责 | 节点 | 建议用途 |
|---|---|---|
| 基础 | 文本 | 默认纯文本输入；一个编辑框、一个 `STRING` 输出 |
| 处理 | 智能文本工作台 | 外接优先、分行、转换、替换、统计、JSON 校验与预览 |
| 处理 | 分割文本、随机选择文本 | 单一、明确的文本变换 |
| 组合与路由 | 多重文本切换、变量输入 | 动态拼接、随机选择、全部输出和变量注入 |
| 文件 | 保存字符串、加载文本文件 | 文本文件读写 |
| 预设 | 提示词预设 | 可复用提示词模板库 |
| 诊断与兼容 | 行数统计 | 只为旧工作流兼容保留 |

## 重复关系与迁移

- “拼接文本”已由支持动态输入及“输出全部”的“多重文本切换”代替，不再注册。
- “模板替换”已由“智能文本工作台”的替换处理以及“变量输入”代替，不再注册。
- “行数统计”的核心结果已由“智能文本工作台”的 `text`、`line_count` 等输出覆盖，因此标记为旧版兼容，不删除。
- `EaglePromptPreset` 是未注册的早期实现；菜单中实际使用功能更完整的“提示词预设”，旧类暂留源码以降低历史迁移风险。
- “文本”与“智能文本工作台”不是重复节点：前者适合纯输入，后者用于加工、检查和预览。
- “智能文本工作台”的拼接/分割分隔符默认为英文逗号 `,`，仍可填写 `\\n`、`\\t` 或 `\\r`。

仍保留的兼容节点继续使用原注册键。“拼接文本”改用“多重文本切换”，“模板替换”改用“智能文本工作台/变量输入”；已移除的“文本条件分支”会在旧工作流中显示为缺失节点。

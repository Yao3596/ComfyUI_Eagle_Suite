# API 生图尺寸说明与回归验证

## 设置含义

- `size=auto`：由服务端决定尺寸；比例、分辨率、自定义宽高不参与计算。
- `size=比例预设`：由 `aspect_ratio` 与 `resolution` 计算最终画布。本节点 4K 定义为长边 3840，所以 3:4 为 2880×3840。
- `size=自定义宽高`：使用 `custom_width/custom_height`，不使用比例预设。
- `size=原图尺寸`：使用第一张参考图的宽高。
- `input_resize_mode`：只处理上传参考图与遮罩，不控制最终输出尺寸。
- `output_resize_mode`：控制 API 返回尺寸与目标不一致时如何处理；新增字段追加在原有字段之后，不调整原字段顺序。

默认“适应留边”保持图片比例，必要时填充画布；“裁剪填满”会损失边缘内容；“拉伸”可能改变人物或文字比例。“保留API原图”明确不强制目标尺寸；“尺寸不符时报错”拒绝不符结果，**不会自动重试**，已完成的 API 请求可能已经计费。原图保留/严格模式下，异尺寸多图不能无损合并为一个 ComfyUI IMAGE 批次，会要求改用单图或适配模式。

## 不把本地缩放当作原生 4K

目标尺寸、请求尺寸、API 实际返回尺寸、最终输出尺寸是不同阶段。现有模型适配器可能限制请求尺寸，兼容服务也可能返回其他尺寸。节点现在直接展示全部四项信息，并注明本地缩放。放大像素不保证恢复文字细节，也不等于模型原生生成了更多细节。

# Eagle H3 Director × MiniMax H3 Context Loop 对齐记录

## 本次已完成

- Skill 生成支持“当前场景”和“全部场景”，全部场景使用动态场景数并串行排队。
- 每次请求携带 `batchId` / `requestId` / `sceneId`，回填时严格校验，不再降级写入“当前场景”或第一场景。
- 任务执行顺序固定为台本 → 分镜 → 台词，不受勾选先后影响。
- 生成上下文包含当前可用参考标签、上一场景结尾和下一场景承接目标。
- 台词任务可读取已生成的分镜，避免台词时码与镜头脱节。
- `<Picture N>` / `<Video N>` / `<Audio N>` / `<d>...</d>` 改为不可拆分的富文本原子标签。
- 点击原子标签可在“启用 / 忽略”之间切换；忽略状态保存在场景数据中，编译时不传给 H3。
- 参考素材重排或删除时，同步改写台本标签和忽略列表。
- Plan 每场景新增 Context Loop 可识别的 `duration_seconds` / `length` / `source_scene_id` / `reference_tags` 字段。
- 场景级 `context_length` / `audio_context_length` / `steps` 支持正确继承全局或显式覆盖。
- 参考素材纳入 `generation_fingerprint`，更换素材会使旧生成检查点失效。
- 恢复运行时比较全局依赖和逐场景生成参数，从最早变化场景起清理失效历史，保留前面未变的成片。

## 已对齐的承接节点能力

- 上一镜末帧上下文自动从 `run_state` 获取。
- 原生 ComfyUI `VIDEO` 端口。
- 分段检查点、审查门、通过 / 重试 / 换种 / 停止。
- 自动模式与交互审查模式。
- 中断恢复、成片合成、接缝预览与偏移建议。
- 前端审查决策路由和预览路由。

## 后续仍有价值，但不应盲目复制的高级能力

1. **场景级参考调度**：当前 Eagle 使用全局媒体包；后续可增加每场景可用标签和时间窗，但需同时改造集成端口节点。
2. **多候选审片**：同一场景保留多个 seed/提示词候选并对比通过，需要候选资产管理，不只是再加一个按钮。
3. **非线性视觉承接**：允许场景 N 从更早场景取上下文、双来源组合上下文；普通顺序短片并不需要。
4. **源音频时间线锁定**：适合 MV/对口型项目，需要为每场景编译音频切片和指纹。
5. **提示词修订历史**：原子标签编辑已稳定后，可增加场景级撤销栈和模型改写差异确认。
6. **更多试验性过渡模式**：Context Loop 的 latent/detail/drift AV 需严格模型和帧长条件；Eagle 暂保留稳定的 guide/masked AV，不将不可验证的模式直接暴露给用户。

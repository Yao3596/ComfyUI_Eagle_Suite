# 媒体剪辑台

`🦅 媒体剪辑台` 是面向 ComfyUI 工作流的轻量非线性剪辑节点。它不替代完整桌面剪辑软件，而是把生成工作流前后最常用的裁剪、拼接、抽帧和音频处理集中在一个可保存的节点中。

## 当前能力

- V1 顺序视频轨：多段视频裁剪、播放头切分、复制、删除和拖拽重排。
- A1/A2 音频轨：独立设置时间线起点、入点、出点、音量、静音和淡入淡出。
- 视频原声：每个视频片段都能单独保留或关闭原声，总开关可一次关闭全部视频原声。
- 节点内素材箱：本机文件可拖入上传；同一素材可反复拖进轨道，不会复制原文件。
- 尺寸处理：跟随首段，或输入自定义宽高；可锁定首段比例，选择完整适应、填充裁剪或自由拉伸。
- 固定输出端口：原生 `VIDEO`、`IMAGE` 帧序列、`AUDIO`、工程 JSON 和状态信息。无需根据模式动态改变端口。
- 工作流持久化：素材引用、轨道片段、剪辑参数和输出设置随工作流保存，刷新或切换工作流不会恢复为默认值。
- 本地渲染：使用 FFmpeg 编码和混音，媒体文件不会上传到外部服务。

“音频分离”在这里是指从视频中拆出并独立控制原声。人声/伴奏/乐器分轨属于源分离模型能力，不在本节点中伪装实现；后续可以把专用分轨节点的输出接入 A1/A2。

## 使用流程

1. 从 `🦅 Eagle Suite/视频` 添加“媒体剪辑台”。
2. 把视频或音频文件拖入顶部区域；上传后视频自动进入 V1，音频自动进入 A1。
3. 单击轨道片段，在预览区下方编辑入点、出点、音量、淡入淡出和原声状态。
4. 单击时间标尺或轨道空白处定位播放头；选择“切分”可从当前位置拆开视频片段。
5. 设置输出内容、尺寸、适配方式、FPS 和帧抽样参数，然后选择“渲染输出”。

也可以连接外部 `VIDEO`、`AUDIO`：当对应轨道为空时，节点会把外接媒体作为默认素材执行。节点内轨道内容优先于同类外接端口。

## 输出模式

- `视频 + 音频`：返回带最终混音的原生 `VIDEO` 和独立 `AUDIO`。
- `视频 + 音频 + 帧`：在上述输出外解码 `IMAGE` 批次。
- `仅图像帧`：只渲染视频画面并解码帧批次。
- `仅音频`：允许没有视频轨，只混合 A1/A2 或外接音频。

没有实际内容的固定端口会返回空值或占位张量，以保持工作流端口顺序稳定；下游应只连接所选输出模式对应的端口。

## 设计边界与后续扩展

首版有意保持为一条顺序视频轨和两条音频轨，避免在 ComfyUI 节点内复制完整专业剪辑软件。适合后续扩展但尚未加入的能力包括：转场、多层叠画、字幕轨、变速/倒放、磁吸与波纹编辑、代理文件、关键帧，以及 AI 人声/伴奏分离。这些能力会优先采用独立、可组合的节点契约，避免破坏已保存的剪辑工程。

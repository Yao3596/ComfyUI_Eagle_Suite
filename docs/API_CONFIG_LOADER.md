# API 配置加载器

编辑 API 模型时，模型名不再锁定。点击「检查连通并读取模型」只会对当前 Base URL 请求 `GET /models`，不会发送聊天、生图或其他推理请求。成功后会显示耗时和模型数量，并在下拉列表中切换模型；仍可手动输入服务端未列出的模型名。

切换后保存会将配置根键同步更名为实际模型名，既有 API Key 在密码框留空时保持不变。如果选中了生图模型，应将模型类型设为「生图模型」；视觉理解模型仍属于 LLM 调用路径。

对于不提供 OpenAI 兼容 `/models` 的供应商，404 只能说明服务可达但不支持列表发现，不能证明某个手填模型不可用。401/403 表示服务拒绝凭据。检测拒绝跟随重定向，避免将 Authorization 头带到其他主机。
